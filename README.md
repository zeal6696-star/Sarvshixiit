# SARVSHIXIIT SIIC-IITK | Attendance Management Portal

An automated Attendance Management Portal developed for SARVSHIXIIT (SIIC, IIT Kanpur).

## 🚀 Features
- Employee & Admin Authentication (Login / Sign Up)
- Dark Mode Support
- Attendance Logging & Real-time Tracking
- Clean and Responsive UI

## 🛠️ Tech Stack
- **Frontend:** React.js / HTML5 / CSS3 / JavaScript
- **Version Control:** Git & GitHub
